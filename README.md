# Camera Store

Camera Store is a comprehensive e-commerce web application built with PHP and Laravel, designed for browsing, filtering, and purchasing photographic equipment with ease. Live demo is available at [kyron.page.gd](https://kyron.page.gd).

## Features

- Dynamic product catalog and advanced filtering.
- Secure user authentication and role management.
- Cart management and checkout workflows.
- Responsive design optimized for cross-device compatibility.
- Deployed on InfinityFree hosting.
